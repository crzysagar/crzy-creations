CRZY CREATIONS WEBSITE — VERSION 1

Open index.html in a browser.

This is a front-end storefront prototype with:
- responsive design
- product catalog
- search and category filters
- wishlist interaction
- cart stored in browser localStorage
- newsletter interaction
- demo checkout
- mobile navigation

To make it a real store, connect a backend/database, real product images, inventory, authentication, order management, payment gateway, shipping, policies and analytics.
